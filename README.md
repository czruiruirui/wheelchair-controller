# 轮椅摇杆控制器固件（wheelchair-controller）

基于 STM32F103C8 的轮椅摇杆控制板固件：读取 KTH5774 摇杆与面板按键，通过 SBUS 协议每 10 ms 向煜禾森（YHS）底盘下发控制帧。

## 硬件连接

| 外设 | 引脚 / 接口 | 说明 |
| --- | --- | --- |
| KTH5774 摇杆 | USART3，921600 波特 | TIM2 定时发送查询帧 `BB 00 DF F8`，返回大端 X/Y 原始值 |
| SBUS 下发 | PA2 / USART2，100000 波特 8E2 | 标准 25 字节 SBUS 帧，帧头 `0x0F`，每 10 ms 一帧 |
| + 按键 | PB15 | 升档位 |
| - 按键 | PB13 | 降档位 |
| SOS 按键 | PB12 | 切换导航模式 |
| 喇叭按键 | PB14 | 切换电子抱闸 |
| POWER 按键 | PA15 | 暂无功能 |
| 档位指示灯 | LED1 / LED2 / GPIOA，低电平点亮 | 逐级指示 1~3 档 |
| 调试器 | CMSIS-DAP（VID_C251 PID_F001） | Keil 工程已配置 |

## 按键功能

| 按键 | 功能 | 行为 |
| --- | --- | --- |
| 喇叭 | 电子抱闸切换 | 按一下松开抱闸（可手动驾驶），再按一下抱死 |
| SOS | 导航模式切换 | 按一下进入导航（CH7 拨到 BOTTON，同时自动松抱闸），再按一下退回手动 |
| + | 升档 | 1 → 2 → 3 档，语音播报并点亮对应 LED |
| - | 降档 | 3 → 2 → 1 档 |
| POWER | 无 | 预留 |

速度档位：通过 **CH9 / SC 三段开关**下发，1 档 = TOP `240`，2 档 = MIDDLE `1024`，3 档 = BOTTON `1807`，由底盘按 SC 位置限速；摇杆始终全量程输出（本地不再做 40/70/100 缩放）。默认上电 1 档。摇杆中心死区 `JOY_DEADZONE_PCT = 15`。

## SBUS 通道映射

通道原始值约定：`240` = -100（TOP），`1024` = 中位（MIDDLE），`1807` = +100（BOTTON）。

| 通道 | 内容 | 取值 |
| --- | --- | --- |
| CH1 | 右摇杆水平 T1 | 摇杆 X，240~1807 |
| CH2 | 左摇杆垂直 T3 | -摇杆 Y（方向已翻转） |
| CH3 | 右摇杆垂直 T2 | -摇杆 Y（方向已翻转） |
| CH4 | 左摇杆水平 T4 | 摇杆 X |
| CH5 | 旋钮 V1 | 固定 1807（速度门控拉满） |
| CH6 | 旋钮 V2 | 固定 1807（速度门控拉满） |
| CH7 | 拨动开关 SA | SOS 导航开关：1807 = 导航，240 = 手动 |
| CH8 | 拨动开关 SB | 电子抱闸：240 = 抱死，1024 = 松开（导航或喇叭松开时为中位） |
| CH9 | 拨动开关 SC | 速度档位：1 档 = 240，2 档 = 1024，3 档 = 1807 |
| CH10 | SD | 固定中位 1024 |

模式联动逻辑（`User/sbus_tx.c`）：

- 手动 + 抱闸：CH7 = 240，CH8 = 240
- 手动 + 松抱闸（喇叭）：CH7 = 240，CH8 = 1024，摇杆直控底盘
- 导航（SOS）：CH7 = 1807，CH8 = 1024（自动松抱闸，底盘由上位机导航控制）

## 工程结构

```
Core/          CubeMX 生成的外设初始化与 main.c
Drivers/       STM32F1 HAL 库
User/          业务代码（GBK 编码，修改时注意保留编码）
  KTH577.*     摇杆驱动
  sbus_tx.*    SBUS 组帧与通道映射
  switch.*     按键扫描（喇叭抱闸 / SOS 导航 / 档位）
  NV080D.*     语音播报
KTH577x_IIC/   摇杆 IIC 相关
RTT/           SEGGER RTT
MDK-ARM/       Keil µVision 工程（control.uvprojx，编译器 V6.19）
control.ioc    CubeMX 配置
```

## 编译与烧录

1. 用 Keil µVision 打开 `MDK-ARM/control.uvprojx`
2. 调试器选择 CMSIS-DAP，板子上电后连接
3. Build（F7）→ Download（F8）烧录，或直接进入 Debug 查看变量

调试时可在 Watch 窗口观察：`Coord_X / Coord_Y`（摇杆解算值）、`Sbus_Ch[]`（各通道原始值）、`Brake_State`（抱闸状态）、`Nav_Mode`（导航状态）、`dangwei`（档位）、`Btn_xxx`（按键电平）。
